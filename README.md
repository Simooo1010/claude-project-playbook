# Claude Project Playbook

A template for building web/mobile apps with Claude Code: spec first, small verified steps, previews tested on a real device, honest hand-offs.

## Start a new project
1. Click **Use this template** → create the new repo.
2. Open a Claude Code on the web session on it.
3. Send the kick-off prompt from `docs/HOW-TO-WORK-WITH-CLAUDE.md` §4.

To add it to an existing repo instead, copy the files below to its root.

## What's inside
```
CLAUDE.md                        # rules Claude reads every turn (Claude fills the <…> after the spec)
SETUP-FOR-OWNER.md               # steps only you can do, kept current by Claude
docs/WORKFLOW.md                 # the method: spec, approval modes, step loop, hand-off, QA gates, rules
docs/SPEC.template.md            # Claude turns it into docs/SPEC.md
docs/HOW-TO-WORK-WITH-CLAUDE.md  # your side + ready prompts
```

You can delete this README in the new project or replace it with the product's own.
